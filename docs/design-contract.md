# Portfolio: direzione e verifica ECC

Portfolio personale di Simone Pacileo. Il visitatore (recruiter o sviluppatore)
deve capire il ruolo Java backend, esplorare progetti reali e trovare CV e contatti.
Riferimenti: brief allegato, CV fornito e API pubbliche GitHub di paci1828.

Direzione: editoriale, tecnica, calma. Fondo avorio, inchiostro verde scuro,
accento smeraldo; font sans per il testo e monospace per metadati e codice.
Dettaglio distintivo: una piccola architettura backend illustrata nel hero.
Gerarchia: presentazione, progetti GitHub, profilo/stack, esperienza, contatto.
Azioni principali: aprire un progetto, scaricare CV, scrivere un'email.

Viewport: 1440x900, 390x844. Griglie 2 colonne desktop / 1 mobile,
menu mobile espandibile, target interattivi di almeno 44px, focus visibile,
nessuno scorrimento orizzontale del documento, supporto reduced motion.

Stati: loading (skeleton stabile), empty (filtri azzerabili), error (riprova e
link GitHub), partial (cache obsoleta o verifica fork incompleta esplicitata),
success (repository e README navigabili). Permission non applicabile:
API pubbliche, nessun accesso account né scrittura remota.

Date interpretate come anno corrente 2026: Luna Labs termina 08/2026;
SNAPPER inizia 09/2026 (metà mese). Aggiornabili nei JSON.
Non aggiungere competenze non documentate come fatti: le tecnologie richieste
nel brief ma non presenti nel CV restano modificabili nella configurazione.
